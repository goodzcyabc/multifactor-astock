# A 股多因子选股策略(中证 800 股票池)

> 面试作业:"完成一个多因子策略,品种任选"。本仓库是一个可一键复现的 A 股多因子选股回测,
> 附带因子检验、组合回测、图表和中文报告(`report/report.md`)。

## 一句话说明

每个月末,用 7 个事先选定的因子(动量、反转、低波动、小市值、低换手、价值、质量)给中证 800 成分股打分,
买入总分最高的 50 只等权持有一个月,下月末重新打分换仓。全程扣交易成本,并与中证 800 指数和
"股票池等权"两个基准比较。

## 复现

```bash
pip install -r requirements.txt
python scripts/01_download.py        # 用 baostock 免费接口下载数据(约 1 小时,可断点续传)
python scripts/02_run_pipeline.py    # 因子检验 + 回测 + 图表,约 10 分钟
python tests/test_core.py            # 单元测试(不依赖数据)
```

或直接 `./run_all.sh`。数据源 baostock 免费、无需注册和 token。

## 关键设计决定

| 决定 | 做法 | 为什么 |
|---|---|---|
| 股票池 | 中证 800 的**时点**成分股(每月末查当时名单) | 用今天的成分股回测过去会有幸存者偏差;中证 800 流动性好,私募可实际交易 |
| 价格 | 后复权 | 分红送股不会造成假跌 |
| 流通市值 | 成交额 ÷ 换手率 | baostock 不直接给市值,该恒等式精确成立 |
| 信号与成交 | 月末收盘算分,下一交易日收盘成交 | 避免用收盘价算分又用同一价格成交的前视 |
| 可交易性 | 剔除 ST、停牌、上市不足 120 日;涨停不买、跌停/停牌不卖 | A 股特有的约束,不处理会高估收益 |
| 成本 | 佣金万 3 双边、印花税卖出万 5、滑点千 1 单边 | 保守的实盘水平 |
| 因子选择 | 7 个因子来自公开文献,**事先固定,不在样本内挑选** | 避免数据窥探 |
| 合成 | 等权 z-score 为主;IC-IR 加权、行业市值中性化作对照 | 等权最不容易过拟合 |
| 基准 | 中证 800 + 股票池等权 | 等权组合天然偏小盘,第二个基准剥离这部分 |

## 主要结果

| | 多因子策略 | 中证 800 指数 | 股票池市值加权(含股息) |
|---|---|---|---|
| 年化收益 | 4.3% | 2.3% | 5.5% |
| 夏普比率 | 0.25 | 0.12 | 0.32 |
| 最大回撤 | −33.7% | −43.0% | −29.8% |
| 年化超额(vs 各基准) | — | +1.9% | **−1.2%** |
| 年化单边换手 | 599% | — | — |

核心结论:**合成因子在统计上高度显著(RankIC 0.083,Newey-West t 值 5.6),但 Top 50 多头组合相对公平基准没有产生 alpha。**
差距来自交易成本(换手 599%,成本拖累 2.2 个百分点)、Top 50 只覆盖全截面最极端的 6%,以及小市值因子预设方向在样本内失败。
加换仓缓冲可把超额提到 3.1%,滚动 IC-IR 加权可到年化 8.8%。完整讨论见 `report/report.md`。
