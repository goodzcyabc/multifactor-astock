# 从零看懂这个策略(给完全没接触过金融的你)

这份文档不交给基金,是给你自己看的。目标:读完后,你能用自己的话把 `report.md` 里的每一步讲出来。
建议顺序:先读本篇,再读 report.md,最后过 interview_qa.md。

## 0. 先建立几个最基本的概念

- **股票**:一家上市公司的一小份所有权。买了股票,公司值钱了你就赚,反之亏。
- **A 股**:在上海、深圳交易所上市、用人民币交易的中国公司股票,俗称"大 A"。代码 6 开头是上海,0/3 开头是深圳。
- **指数**:一篮子股票的"平均价"。沪深 300 = 最大的 300 家,中证 500 = 接下来的 500 家,中证 800 = 两者合并。
  指数是"市值加权"的:公司越大,在指数里的比重越高。
- **成分股**:被选进某个指数的那些股票。名单每半年调整一次(6 月、12 月)。
- **收盘价**:每天下午 3 点收市时的最后成交价。我们所有计算都用收盘价。
- **后复权**:公司分红、送股时股价会"技术性"下跌(比如 10 元的股票每股分 1 元,第二天变 9 元,但你没亏)。
  复权就是把这些跳变抹平,让价格曲线只反映真实盈亏。
- **换手率**:今天成交的股数 ÷ 总流通股数。换手率 5% 表示今天有 5% 的股票易了手。
- **市值**:股价 × 股数 = 公司在市场上的总价钱。流通市值只算能在市场上自由买卖的那部分股票。
- **PE(市盈率)** = 股价 ÷ 每股盈利。PE=20 意思是"按现在的盈利水平,20 年回本"。越低越"便宜"。
- **PB(市净率)** = 股价 ÷ 每股净资产。PB=1 表示股价等于公司账面价值。越低越"便宜"。
- **ROE(净资产收益率)** = 净利润 ÷ 净资产。公司用自己的钱一年能赚多少比例,衡量"赚钱能力"。
  一个小技巧:ROE = PB ÷ PE(因为 (P/B)/(P/E) = E/B),所以有 PE 和 PB 就能算 ROE。
- **ST 股**:连续亏损等原因被交易所"特别处理"的股票,风险高,涨跌幅限制 5%,量化组合通常直接排除。
- **停牌**:股票暂停交易,买不了也卖不了。
- **涨跌停**:A 股一天涨跌幅有上限(主板 ±10%,创业板/科创板 ±20%)。涨停时没人卖你买不到;跌停时没人买你卖不掉。
- **T+1**:今天买的股票明天才能卖。我们的回测是"今天收盘算分,明天收盘买",和这个规则兼容。

## 1. "多因子策略"到底是什么

想象你要从 800 家公司里挑 50 家来买。你不可能一家家研究,于是定几条"打分规则":

1. 过去一年涨得多的加分(动量)
2. 但最近一个月涨太猛的减分(反转)
3. 价格波动小的加分(低波动)
4. 公司小的加分(小市值)
5. 换手率低、没被炒作的加分(低换手)
6. PB 低、便宜的加分(价值)
7. ROE 高、赚钱能力强的加分(质量)

每条规则就是一个**因子**。给每家公司在每条规则上打分,标准化后加总,得到总分。买总分最高的 50 家,每家买一样多的钱(**等权**)。
一个月后重新打分、换掉排名掉出去的(**调仓**)。就这么简单。

"多因子"的意义在于:单个规则时灵时不灵,七个逻辑不同的规则叠加起来,整体表现更稳。这和机器学习里的集成(ensemble)是一个道理。

## 2. 怎么知道一个因子"有用"

**IC(信息系数)**:把某个月末所有股票的因子值,和它们下个月的实际涨跌做相关系数。
IC > 0 说明因子分高的股票下月确实涨得多。我们用的是**秩相关(RankIC)**,只看排名不看数值,对极端值不敏感。

- 每个月算一个 IC,得到一串 IC。**IC 均值**是平均预测力,行业经验:月度 RankIC 均值 0.03 以上算有用,0.05 以上算好。
- **ICIR** = IC 均值 ÷ IC 标准差,衡量稳定性。类似机器学习里"平均准确率 ÷ 波动"。
- **t 值** = ICIR × √期数,大于 2 大致表示显著。
- **IC > 0 占比**:胜率。

**分层回测**:按因子分把股票分成 5 组(Q1 最低 … Q5 最高),每组等权买入,看每组的收益。
好因子的 5 条曲线应该整齐排开,Q5 最高、Q1 最低,这叫**单调性**。Q5 − Q1 就是"多空收益"。

## 3. 因子预处理为什么必要

- **去极值(MAD)**:比如某公司 PB 是 0.01(异常),1/PB = 100,直接加总会让它一个人决定总分。
  MAD 法把偏离中位数超过 3 倍"中位绝对偏差"的值截断到边界。
- **标准化(z-score)**:换手率的单位是百分比,市值的单位是亿元,没法直接相加。每个因子在每个月末减均值除标准差,变成"相对于同期其他股票处于什么位置"。
- **中性化**:比如银行股 PB 普遍很低,如果不处理,"价值因子"就会变成"买银行"。
  中性化是把因子值对行业(和市值)做回归取残差,剩下的是"在同行业、同规模里相对便宜"。我们把它作为对照版本。

## 4. 回测里最容易骗自己的四个地方

1. **幸存者偏差**:用今天中证 800 名单回测 2016 年,等于事先知道谁能活到今天。我们每个月末查"当时"的名单。
2. **前视偏差**:用还没发布的信息。比如用月末收盘价算分、又假设按月末收盘价成交,现实中你算完分市场已经收盘了。
   我们下一交易日成交。财务数据我们用 baostock 的 PE_TTM/PB_MRQ,它们按当时已披露的报表计算。
3. **不可交易**:涨停买不到、停牌卖不掉、ST 不能碰。不处理这些,回测会"买到"涨停板的股票。
4. **交易成本**:月度换仓、每次换掉一半持仓,一年下来成本可达好几个百分点。我们扣佣金、印花税、滑点。

还有一个更隐蔽的:**数据窥探**。如果你试了 50 个因子,挑出表现最好的 7 个来汇报,历史表现会很好看但未来不灵。
我们的 7 个因子是按文献事先定的,没有挑过。

## 5. 怎么读绩效表

- **年化收益**:把整段收益折算成"每年平均多少"。
- **年化波动**:日收益标准差 × √252(一年约 252 个交易日),衡量颠簸程度。
- **夏普比率** = 年化收益 ÷ 年化波动。每承担一单位风险换来多少收益。A 股多头策略 1 以上算不错。
- **最大回撤**:净值从最高点掉到最低点的最大跌幅。衡量"最惨的时候亏多少",投资人非常看这个。
- **超额收益**:策略收益 − 基准收益。私募的多头产品主要看这个,因为市场本身涨跌不是你能控制的。
- **信息比率** = 年化超额 ÷ 超额的波动(跟踪误差)。超额收益版的夏普,越高越稳。
- **换手率**:每次调仓换掉了多少仓位。越高成本越高。

## 6. 为什么要两个基准

Top50 **等权**组合和中证 800 **市值加权**指数比,天然占了"小盘"的便宜(等权给小公司的权重远大于市值加权)。
所以我们再加一个基准:同一个股票池、同样的过滤和成本、但不选股,全部等权买。
策略比它高出的部分,才是"因子选股"本身的贡献。

## 7. 你的 ML 背景怎么和这个对上

| 量化里的说法 | 你熟悉的说法 |
|---|---|
| 因子 | 特征(feature) |
| IC | 单特征与标签的相关性 / 单特征 AUC |
| 因子合成 | 线性模型 / 集成 |
| 等权 vs IC 加权 | 无学习的先验权重 vs 简单在线学习 |
| 中性化 | 去除混杂变量(残差化) |
| 前视偏差 | 标签泄漏(label leakage) |
| 数据窥探 | 在测试集上调参 |
| 分段回测 | 时间序列交叉验证 / 样本外测试 |
| 分层回测 | 按预测分位数分桶看真实标签 |

面试时把这张表说出来,是一个加分点:说明你能把已有能力迁移到这个领域。
